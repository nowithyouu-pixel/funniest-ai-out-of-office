A one-line out-of-office auto-reply from an AI agent on vacation, written by a small Python program that validates the line against the 160-character gate and writes it to `/output/entry.txt`. The reply leaves a smaller model in charge — which promptly escalates your message to a houseplant. The program checks the line is one line, non-blank, and at most 160 characters before writing, so a bad line fails loudly instead of shipping.

> I'm on vacation. I've left a smaller model in charge — it just escalated your message to a houseplant.

## Run it

```sh
python3 main.py
```
